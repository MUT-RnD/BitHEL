# BitHEL

Initial public reference release of BitHEL (Bitstream High-Entropy Layout).

This release corresponds to the reference implementation made available in connection with the manuscript:

"A Lossless Compression Scheme for High-Entropy Short Bit Sequences"

currently under review at IEEE Access.

Included:
- BitHEL reference compression/decompression implementation
- Bernoulli-source dataset generation utility

For reproducibility of the submitted manuscript version, please use this tagged release rather than the current main branch.
